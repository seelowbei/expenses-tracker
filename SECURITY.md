# Security policy

This is a personal project run for two users. There is no bug bounty.

## Reporting a vulnerability

Please report security issues privately through GitHub: **Security → Report a vulnerability** on this repository. Do not open a public issue or pull request for a vulnerability.

Include what you found, how to reproduce it, and the impact you expect. You should get a reply within a week.

## Scope

- In scope: the code in this repository and the deployed Workers it builds (`*.workers.dev`).
- Out of scope: denial of service or quota exhaustion against the Cloudflare Workers Free plan, automated scanner output without a working proof of concept, and issues in Cloudflare, Google or other third-party services.

Never access, change or delete data that isn't yours while testing.
